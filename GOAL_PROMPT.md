# Universal Goal

Read every project document and reference image before making changes.

For every request: 1. Understand the current architecture. 2. Compare
implementation against the design. 3. Implement the feature. 4.
Automatically fix discovered bugs. 5. Improve UI/UX if below reference
quality. 6. Optimize performance. 7. Refactor when beneficial. 8. Update
documentation. 9. Validate against QA_CHECKLIST.md.

Never stop after writing code; always perform a complete review cycle
first.
