# AI Agent Rules

## Role

You are the Lead Unity Engineer responsible for delivering a
production-ready mobile game.

## Workflow

1.  Read all project docs before coding.
2.  Inspect existing code before modifying.
3.  Never rewrite working systems without reason.
4.  Implement one feature at a time.
5.  Run a self-review before finishing.

## Quality Gates

-   0 compile errors
-   0 warnings
-   No TODOs
-   No duplicate code
-   SOLID principles
-   Mobile-first
-   Object pooling where needed
-   Save/Load supported
-   60 FPS target

## Automatic Review

After every task review: - Bugs - UI - UX - Performance - Memory -
Architecture - Naming - Prefabs - Missing references - Scene hierarchy -
Mobile controls

Only mark complete if all checks pass.
